GazeGlide – Bluetooth Controlled Eye Movement System

Project Overview

GazeGlide is an Arduino-based project developed for our college Onam celebration. It uses Bluetooth communication and dual servo motors to control eye movement.

Components Used

- Arduino
- Two Servo Motors
- Bluetooth Module
- Power Supply

Working Principle

Bluetooth commands are received by the Arduino, which controls the servo motors to produce eye movements.

Technologies Used

Arduino, Embedded Systems, Bluetooth Communication, Servo Motor Control.
